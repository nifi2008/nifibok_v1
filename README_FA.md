# TipTrack — دفتر هوشمند انعام

اپلیکیشن اندرویدی آفلاین برای ثبت انعام‌های روزانه و پیگیری تسویه هفتگی.

## امکانات نسخه 1
- داشبورد مجموع انعام‌های هفته کاری
- چرخه هفته از پنجشنبه تا چهارشنبه
- ثبت مبلغ، نام مشتری، شماره تماس، توضیحات و تاریخ/ساعت دلخواه
- تاریخ شمسی در نمایش رکوردها
- ویرایش و حذف رکورد
- وضعیت تسویه‌شده / تسویه‌نشده
- ثبت تسویه هفتگی و آرشیو باقی ماندن رکوردها
- تاریخچه تمام انعام‌ها
- خروجی CSV
- ذخیره‌سازی محلی SQLite و عملکرد آفلاین

## ساخت APK
1. محتویات مخزن را در GitHub آپلود کنید.
2. وارد Actions شوید.
3. گزینه Build TipTrack APK را انتخاب و Run workflow را اجرا کنید.
4. فایل `TipTrack-APK` را از Artifacts دانلود کنید.
5. ZIP را استخراج و `app-debug.apk` را نصب کنید.

## نکات
- مبلغ‌ها در این نسخه به تومان ثبت می‌شوند.
- تاریخ انتخابی از Date Picker سیستم گرفته می‌شود و در فهرست با تقویم شمسی نمایش داده می‌شود.
- هفته کاری از پنجشنبه ساعت ۰۰:۰۰ تا پنجشنبه بعدی ساعت ۰۰:۰۰ است.
- اطلاعات فقط روی همین گوشی ذخیره می‌شوند. پاک کردن داده برنامه یا حذف برنامه ممکن است اطلاعات را از بین ببرد؛ خروجی CSV را مرتب ذخیره کنید.
- این نسخه اولیه است و قبل از استفاده طولانی‌مدت، صحت ثبت و خروجی گرفتن را با چند رکورد آزمایشی بررسی کنید.
